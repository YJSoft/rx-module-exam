1. 템플릿 다운로드

UTF-8 CSV 템플릿입니다. Excel에서 열어 예시 행을 수정하거나 필요한 행을 추가하세요.

{$lang->cmd_csv_template_download}

필수 주의사항

  • 공통지문 행은 반드시 연결할 모든 문제 행보다 아래에, CSV의 마지막 부분에 작성해야 합니다.
  • 공통지문 행의 문제번호는 반드시 비워 두세요. 문제범위만 1~3 형식으로 입력합니다.
  • 문제번호가 CSV 안에서 중복되면 마지막 행으로 덮어씁니다. 현재 시험에 같은 번호가 있으면 해당 기존 문제도 덮어씁니다.
  • 새 문제번호는 현재 마지막 문제의 다음 번호부터 빈 번호 없이 연속되어야 합니다. CSV에 없는 기존 문제는 삭제되지 않습니다.
  • 이미 다른 공통지문에 연결된 문제범위는 다시 연결할 수 없습니다.
  • 객관식 정답은 보기 번호를 입력합니다. 복수 정답은 1,3처럼 쉼표로 구분하며, 선택한 답이 모두 일치해야 정답입니다.
  • 모든단어·일부단어 채점은 정답 칸에 단어를 쉼표로 2개 이상 구분해 입력합니다.
CSV 열 입력 방법
열입력 방법
문제번호1 이상의 정수. 공통지문은 빈칸.
난이도하, 중, 상 중 하나. 공통지문은 빈칸 가능.
문제유형객관식, 주관식, 공통지문 중 하나.
문제범위공통지문만 1~3 형식으로 입력.
문제문제 제목. 공통지문에서는 지문 제목으로 사용.
지문 사용 여부Y 또는 N. 공통지문은 자동으로 Y 처리.
지문 머리글/본문본문은 HTML 입력 가능. 위험한 태그는 가져올 때 제거.
(공통) 정답객관식은 보기 번호, 주관식은 정답 또는 정규식.
객관식 보기 1~5사용할 보기 내용을 입력. 사용하지 않는 보기는 빈칸.
주관식 채점 기준완전일치, 모든단어, 일부단어, 정규식 중 하나.
해설/배점해설은 일반 텍스트, 배점은 0~100 정수.
